# 📊 Tableau de bord Power BI – Projet de Business Analysis

## 📌 Présentation du projet

Ce dépôt contient un projet académique de Business Analysis portant sur la conception et la réalisation d’un tableau de bord interactif avec Power BI.

Le projet a été réalisé dans le cadre d’un cours de Business Analysis, sous encadrement académique. Il vise à démontrer la capacité à transformer des données brutes en informations claires et exploitables, afin d’aider à la prise de décision.


## 🎯 Objectifs du projet

 Analyser un jeu de données métier
 Identifier et définir des indicateurs clés de performance (KPI) pertinents
 Concevoir un dashboard Power BI interactif et lisible
 Faciliter la prise de décision basée sur les données
 Mettre en pratique les concepts fondamentaux de la Business Analysis


## 🧩 Contexte métier

Le tableau de bord répond à un besoin classique des organisations :

 disposer d’une vision globale de la performance,
 suivre l’évolution des indicateurs dans le temps,
 identifier les leviers et les axes d’amélioration.

Ce projet simule le rôle d’un Business Analyst / Data Analyst, faisant le lien entre les besoins métier et l’analyse des données.



## 📂 Description des données

Le jeu de données utilisé est composé de données structurées liées à la performance.

Caractéristiques principales :

* données nettoyées et préparées à l’analyse,
* données adaptées aux agrégations et comparaisons,
* données permettant le calcul de KPI pertinents.

> ⚠️ Les données sont utilisées exclusivement dans un cadre académique.



## 📊 Fonctionnalités du tableau de bord

Le tableau de bord Power BI comprend notamment :

 des indicateurs clés de performance (KPI),
 des graphiques interactifs,
 des filtres et segmentations dynamiques,
 une analyse des tendances dans le temps,
 des comparaisons entre catégories.

Le dashboard est conçu pour être :

* clair,
* interactif,
* orienté décision.



## 🛠 Outils et technologies utilisés

* Power BI Desktop – modélisation et visualisation des données
* Power Query – nettoyage et transformation des données
* DAX – création de mesures et d’indicateurs calculés



## 🧠 Compétences mobilisées

* Business Analysis
* Analyse de données
* Data visualisation
* Définition de KPI
* Modélisation de données
* Aide à la prise de décision



## 🚀 Utilisation du projet

1. Cloner ou télécharger le dépôt
2. Ouvrir le fichier `.pbix` avec Power BI Desktop
3. Explorer le tableau de bord à l’aide des filtres et interactions

Il vise à démontrer la capacité à :

* traduire ce besoin en indicateurs et visualisations,
